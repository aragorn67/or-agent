## CSV File Format

### Columns in FINAL_ML_DATASET.csv

**Core Fields (always present):**
- `id` - Unique identifier (e.g., "jobshop/orlib/001", "lpwp/prob_42")
- `title` - Human-readable title
- `text` - Natural language problem description (THIS IS THE INPUT)
- `level1_family` - High-level category (e.g., "scheduling", "transportation")
- `subtype` - Specific problem type (e.g., "job_shop", "knapsack") **← TARGET FOR CLASSIFICATION**
- `key_clues` - Space-separated keywords
- `numbers_present` - "yes" or "no"
- `integrality_implied` - "yes" or "no" (integer variables)
- `source_url` - Data source identifier

**Optional Metadata Fields:**
- `num_jobs`, `num_machines` - For scheduling problems
- `num_sources`, `num_sinks` - For transportation
- `num_items`, `num_constraints` - For knapsack
- `num_facilities`, `num_customers` - For facility location
- `bin_capacity`, `capacity`, `size` - Problem-specific
- `source_type` - "LPWP", "ComplexOR", etc.

## Usage Examples

### Load Dataset
```python
import csv

with open('knowledge/FINAL_ML_DATASET.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    data = list(reader)

print(f"Total instances: {len(data)}")

# Get texts and labels for classifier
X = [row['text'] for row in data]
y = [row['subtype'] for row in data]  # 24 possible classes
```

### Filter by Family
```python
# Get only scheduling problems
scheduling = [row for row in data if row['level1_family'] == 'scheduling']
print(f"Scheduling problems: {len(scheduling)}")  # 220 instances
```
